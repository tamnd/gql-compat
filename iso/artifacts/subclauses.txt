# Clause and subclause structure of ISO/IEC 39075:2024 (GQL), edition 1.
#
# Unlike features.xml, conditions.xml and the grammar, ISO publishes no
# machine-readable artifact for the document's own structure — and mandatory
# features carry no feature code, so the subclause number is the only handle a
# conformance claim has on them. This file supplies that handle.
#
# It is transcribed from the table of contents in the publicly downloadable
# preview of the standard:
#   https://cdn.standards.iteh.ai/samples/76120/a5695073ca0a485c9929f50970f4c862/ISO-IEC-39075-2024.pdf
# (contents pages iii-xi), which ISO and its resellers publish free of charge.
# Only numbers and titles are reproduced: no normative text of the standard is
# copied here, and none is needed — a corpus cites a subclause, it does not
# quote it.
#
# Format is "number<TAB>title", one per line, in document order. Titles keep
# the standard's own spelling, including the angle brackets it puts around
# syntactic elements, so a report can be read next to the document.
#
# A number in this file is not a promise that gql-compat tests it. It is the
# denominator: the report says how many of these a run actually exercised.
